## 最小改动

- src/dailySectionSanitizer.js：不再凭标题替换锚文本。来源标签后紧接一个完整、短且无嵌套 Markdown 的事实分句时，仅移动链接括号到该分句，保留原先所有可见字词和 URL。长链接只有存在完整标点分句时缩小链接范围，剩余字词留在正文。无法安全识别时原样保留，交给已有编辑/修复，不猜短标题、不截词、不跨句、不加省略号。仍只处理 TOP 的原有范围。
- src/dailyRepairPolicy.js：解析已有长句警告的数量和最长句严重程度。只影响两个已生成稿的选择，不增请求、不改变发布合格标准；初稿有效且修复无收益时保留初稿，初稿无效而修复有效时仍正常采用修复。
- src/prompt/summarizationPromptStepZero.js 与 scheduled.js 的 repair 文本：恢复清楚的短句分工，署名依旧可选；用完整范例展示短结论、事实链接、两个独立细节、限制，不强制行动结尾。保留黄色重点、TOP 120-170 字和其余栏目篇幅，不增加新检查点。

## 验收与风险

- 不把标题注入正文链接；对可处理样本，去除 Markdown 标记后的字词与 URL 集合保持一致；不可处理的嵌套、带 title、复杂 URL 保持原样。
- 标点/括号移动不能删除否定、测试条件或来源归属。图片不被当作文字链接修改。
- 新评分有专门的退化和改善用例；无效稿不发布；有效初稿不因写作问题被新增规则阻断。
- 不保证所有来源标签都能自动变成优美事实短语；不扩展成自然语言重写器。
- 不对全部现有文章做批量修订，不无授权修改原站内容。
- 发布期间若有其他任务更新，保留并合入，不强推。回滚只 revert 本轮提交，不回退整个旧 Worker 以覆盖他人改动。
