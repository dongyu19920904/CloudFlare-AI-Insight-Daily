# AI 日报速读改造方案（2026-08-06）

## 目标

保留已经生效的去空话、具体角色和事实边界规则，同时修复单条内容被压成一个超长句的问题。日报主体、采集、Cron、商机任务和发布隔离不在本轮修改范围内。

## 基线

同一批 2026-08-06 缓存素材重跑前后对比：

| 指标 | 修改前 | human-writing 接入后 |
| --- | ---: | ---: |
| 平均句长 | 42.6 | 48.4 |
| 90 分位句长 | 70 | 90 |
| 超过 70 个可见字符 | 6 / 62 | 12 / 54 |
| 分号数量 | 3 | 8 |
| 常见空泛表达 | 4 | 1 |

现有改造减少了空话，但形成“短结论 + 超长证据句”的两段式结构。正文总长度并未失控，主要问题是信息分配和停顿不足。

## 最小修改

1. 调整 `src/prompt/summarizationPromptStepZero.js`：
   - 每条使用 2-4 个完整短句。
   - 结论、证据、影响或动作分别成句。
   - 普通句子优先 18-32 个显示字符，超过 35 主动拆分，原则上不超过 55。
   - 不用分号串联多个独立判断。
   - 缩短链接文案，减少黄色重点数量。
2. 扩展 `src/dailyWritingQuality.js`：
   - 统计可见句长、90 分位、最大句长和分号数量。
   - 只产生非阻断警告，不改变发布结果。
3. 更新现有测试，覆盖提示词约束和可读性统计。

## 验收

- 现有测试全部通过。
- Wrangler dry-run 通过。
- 正式重跑 2026-08-06 后，90 分位句长低于当前 90，超过 70 字的句子明显减少。

- 可读性警告、趣闻失败或单条风格问题不阻止日报发布。
